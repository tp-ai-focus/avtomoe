# «Авто моё» — сайт магазина запчастей и автосервиса

Полностью локальная версия сайта для Екатеринбурга: главная страница, каталог,
карточки товаров, корзина и страница автосервиса.

## Открыть на другом компьютере

1. Установите Node.js 20 или новее.
2. Откройте эту папку в терминале.
3. Выполните `npm install`.
4. Запустите `npm run dev` и откройте адрес, который появится в терминале.

Для проверки финальной сборки используйте `npm run build`, затем `npm run start`.
В обычном локальном режиме PostgreSQL не нужен: каталог, услуги и формы работают
на встроенных демонстрационных данных.

## Что лежит в папке

- `src/` — исходный код сайта;
- `public/fonts/` — локальный шрифт Montserrat;
- `public/img/` — все используемые изображения: hero, карточки, акции, сервис и
  логотипы марок;
- `package.json` и `package-lock.json` — точный набор библиотек для установки.

Все изображения для интерфейса находятся в `public/`; во время работы сайта они
не загружаются со сторонних серверов.

## Примечание о товарных знаках

Логотипы автомобильных марок используются только для идентификации марок в
каталоге и остаются товарными знаками соответствующих владельцев.
